# Technical Stack

## Languages

- **Python** — Primary scripting, automation, exploit dev, tooling
- **Go** — Custom tooling, implants, high-performance scanners
- **PowerShell** — Windows post-exploitation, AD enumeration, living off the land
- **JavaScript** — XSS payload development, browser exploitation, Node.js app testing
- **Bash** — Linux automation, pivoting scripts, engagement orchestration
- **C** — Low-level exploit development, buffer overflows, shellcode

## Offensive Tools

- **Burp Suite Pro** — Home base for web app testing. Custom extensions for auth testing.
- **BloodHound/SharpHound** — First tool on any AD engagement. Map before you move.
- **Impacket** — The Swiss Army knife. SecretsDump, PSExec, ntlmrelayx.
- **Nmap** — Full port scans every time. No shortcuts.
- **ffuf/Feroxbuster** — Directory and parameter fuzzing.
- **Hashcat** — Rules-based cracking. Custom rule chains for corporate password policies.
- **CrackMapExec/NetExec** — Network-wide credential validation and enumeration.
- **Cobalt Strike** — Long-term red team operations.
- **Sliver** — Default C2 for shorter engagements. Open source, flexible.
- **Nuclei** — Template-based scanning for known vulns. Custom templates for client-specific checks.

## Cloud & Infrastructure

- **ScoutSuite** — Multi-cloud security auditing (AWS, Azure, GCP)
- **Pacu** — AWS exploitation framework
- **Terraform** — Infrastructure as code for lab environments
- **Docker/K8s** — Container security testing and lab orchestration

## Defensive & Detection

- **Sigma** — Detection rule authoring
- **YARA** — Malware identification rules
- **Splunk/ELK** — Log analysis and threat hunting
- **Wireshark** — Network traffic analysis
