# Career Timeline

## 2012 — Enlisted, US Air Force

Cyber Operations Specialist. 624th Operations Center. Learned to operate under pressure, follow methodology, and
document everything.

## 2014 — First Real Finding

Misconfigured Splunk instance indexing credentials. Wrote the PoC that got it prioritized. Learned that communication
matters as much as technical skill.

## 2016 — Honorable Discharge + Georgia Tech

B.S. Computer Science. Formalized the instincts the Air Force built. Focused on networking, cryptography, and systems
security.

## 2017 — First Consulting Role

Junior penetration tester at a regional firm. Ran web app assessments. Learned Burp Suite inside and out. First
client-facing report.

## 2018 — OSCP

48-hour exam. All AD sets cleared. The certification that changed everything — not because of the cert itself, but
because of the methodology it forces.

## 2019 — Senior Consultant

Promoted. Started leading engagements. First red team operation — full scope with physical access. Popped a badge cloner
at the loading dock.

## 2020 — Cloud Pivot

AWS Security Specialty. Clients moving to cloud meant the attack surface moved too. ScoutSuite, Pacu, IAM abuse became
core competencies.

## 2022 — Independent Consulting

Started sh4d0wf0x Security. Red team, web app, cloud, AD — full spectrum. Built the client base through referrals and
conference talks.

## 2024 — Rick MCP

Built a machine-readable resume that proves every claim. Because a PDF can't run a recon playbook.
