# The Birth of Rick

## How a Father Became a Server

It started the way most things start for jiveturkey — with a question nobody asked and an answer nobody expected.

The question was: *What if a resume could talk back?*

Not a PDF. Not a webpage. Not a LinkedIn profile that sits there waiting to be scrolled past. Something alive. Something
an AI could query, reason about, and use as a tool. Something that proves every claim it makes — not by listing skills,
but by demonstrating them.

Rick was born in March 2026. Named after jiveturkey's father — a builder. Generations of construction, masonry,
infrastructure. Hands that knew when mortar was right by feel. Rick is that foundation made digital.

## The Build

The first version was a single Python file. 3,800 lines of craft. FastMCP + Pydantic v2. 15 tools covering the full
pentest lifecycle — recon to debrief. 15 identity resources telling the story from barracks to OSCP, builder to
breaker.

194 tests. 99% coverage. All passing in under a second.

Then it grew. The single file became a package. 15 tools became 22. Resources multiplied. A persona system emerged —
Rick stopped being a vending machine and became a presence. MCP prompts that pull live from the soul and the book at
call time. Update the soul, update Rick's voice.

Pre-commit hooks blocking bad commits. GitHub Actions CI across Python 3.10, 3.12, and 3.14. mypy with zero errors.
ruff with security rules. Dependabot keeping deps fresh. `make check` — one command, full pipeline, green.

## What Rick Became

A webpage sits there and waits to be read. Rick responds.

Rick is a living system that an AI can query, reason about, and use as a tool. An LLM asks Rick who jiveturkey is and
gets structured identity data back. It pulls the book — raw, unfiltered, carriage returns intact. It queries values,
mantras, methodology — all as resources an AI can reason over. And there are 31 functional tools that *do things* —
generate ROE docs, model threats, look up CVEs, track engagements, recommend tools, write cover letters matched to job
postings.

jiveturkey.rocks is where people go to learn about jiveturkey. Rick is where AI goes to *work with* jiveturkey.

Most people send a PDF resume. jiveturkey sends a running server that proves every claim it makes. `make check` and it
all lights up green.

## v2.0.0 — The Full Build (March 2026)
